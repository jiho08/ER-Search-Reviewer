# 수행평가 준비 현황

원문: [수행평가 4 대체 과제 시트](https://docs.google.com/document/d/1U5KLOvj3kATbzr4lgBHIQqg6ji5wFsUb/edit)

주제: 이터널 리턴 전적 검색 및 개인 플레이 리뷰 에이전트. 여러 주제를 추가하는 대신 이 한 흐름의 완성도를 높인다.

현황 확인일: 2026-09-15. 로컬 코드·문서·결과보고서에서 확인한 준비 상태이며 외부 게시를 추정하지 않는다.

2026-09-16 개발 상태 추가: Cloudflare 공개용 설정과 SQLite 공유 전적·요청 제한을 구현하고, 41개 자동 테스트·타입 검사·공개용 빌드·배포 dry-run·로컬 HTTP를 확인했다. 실제 공개 배포와 URL 발급은 아직 진행하지 않았다. 이는 아래 평가·제출 항목을 새로 충족했다고 판정한 기록이 아니다. 사용자가 이후 실행 영상을 업로드했다고 알려 주었으며, 아래 2026-09-15 보고서 확인 기록은 당시 상태로 유지한다.

| 평가 항목            | 현재 상태                                               | 제출 전 필요한 작업                      |
| -------------------- | ------------------------------------------------------- | ---------------------------------------- |
| 주제 선정 및 구현    | 실제 전적·시즌 조회, 대시보드, 분석 도구 4개·리뷰 서버 구현 | 주요 코드와 실행 화면을 보고서에 첨부 |
| 완성도               | 실제 ER 조회·Codex 예시 리뷰 검증, 34개 자동 테스트·타입 검사 통과 | 본인 전적 검색부터 Codex 리뷰까지 최종 시연·캡처 |
| 개발·사용법 문서     | README, API 조사, 개발 기록·설치법·오류 해결 사례 작성 | 보고서에 개발 과정 요약·문서 근거 반영 |
| 직접 사용한 후기     | 작성 양식 제공                                          | 본인이 실제로 사용한 후 직접 작성        |
| 블로그 또는 SNS 게시 | 제공된 자료에 게시 링크 없음                            | 완성본·후기 게시 후 링크 기록            |
| GitHub 업로드        | 코드·README·개발 이력을 main에 업로드하고 원격 커밋 확인 완료 | 보고서 5번에 저장소 링크 기입 |

ER 키는 2026-09-14에 실제 닉네임·시즌 랭크 조회 성공을 확인했다. 물방개 시즌 12는 33페이지에서 랭크 170경기를 확보해 공식 누적 170경기와 일치했다. Codex는 예시 전적 분석으로 실제 연결을 검증했다. 이 검증을 사용자 본인의 실사용 후기나 실제 전적의 Codex 최종 시연으로 대신 표시하지 않는다.

## 공개 사이트 여부

원문은 완성도 조건에 “정상 배포·실행”을 적고 있으나 공개 서비스 주소·도메인·상시 운영을 명시하지 않는다. 제출 링크는 블로그/SNS와 GitHub다. 로컬 실행·시연과 코드 공유를 중심으로 준비하되, 외부 배포가 필요한지는 교사의 별도 안내를 확인한다. 공개 사이트를 과제 필수 완료 항목으로 임의 추가하지 않는다.

## 제출 자료

1. 코드: `lib/server/review-tools.ts`의 등록 도구, `selectTools` 선택 로직, `scripts/codex/app-server.ts`의 동적 도구 등록·실행과 최종 리뷰 검증.
2. 화면 캡처: 예시 안내가 보이는 전적 화면, 실제 본인 전적 조회 화면, 리뷰 결과 및 도구 내역. 예시 캡처를 실제 전적으로 설명하지 않는다.
3. 개발 과정: README와 `docs/development.md`.
4. 사용 후기: `docs/usage-review-template.md`를 본인의 사용 경험으로 완성.
5. 게시 링크·GitHub 링크: 실제 게시·업로드가 끝난 뒤 기록.

GitHub 게시 링크: [jiho08/ER-Search-Reviewer](https://github.com/jiho08/ER-Search-Reviewer). 2026-09-15에 코드·문서 144개 파일을 업로드하고 원격 main을 확인했다. 기존 저장소의 커밋 이력과 로컬 개발 이력을 함께 보존했다.

2026-09-15에 확인한 [결과보고서](https://docs.google.com/document/d/1HGG_s0L3f1VJWTn1rrR5g6ZDA8r79YssaQV5CDKzhRs/edit)는 인적 사항·안내문만 있으며 본문, 캡처, 게시 링크가 비어 있다.

채점표는 6개 모두 충족 30점, 이후 한 항목씩 줄어들 때 26·22·18·14·10점이다. 이 문서는 제출 준비 상태를 정리하며 성적 충족을 보증하지 않는다.
