# 전적 대시보드 확장 근거

확인일: 2026-09-14. 사용자 지정 [DAK.GG 물방개 전적](https://dak.gg/er/players/%EB%AC%BC%EB%B0%A9%EA%B0%9C)을 읽고, 티어·랭킹, 주요 지표, 실험체별 성적, 특성·장비가 나란히 보이는 경기 구성을 참고했다. 기존 LUMIA의 어두운 배경과 라임·청록·보라 색상은 유지한다. 예시 기록은 자체 생성한 가상 데이터이며 물방개 플레이어의 실제 기록을 복제하지 않는다.

## 지표와 데이터 범위

[공식 Open API 명세 §2–3](https://developer.eternalreturn.io/static/media/OpenAPI_KR_20260724.html)에 따라 다음 필드를 사용한다.

| 화면 | 공식 필드 / 계산 |
|---|---|
| 최종 장비 | `equipment`의 0 무기, 1 옷, 2 머리, 3 팔, 4 다리 |
| 핵심·보조 특성 | `traitFirstCore`, `traitFirstSub`, `traitSecondSub` |
| 전술 스킬 | `tacticalSkillGroup`, `tacticalSkillLevel` |
| 팀 전체 처치 | `teamKill` (개인 킬·어시스트 합으로 추정하지 않음) |
| 킬·사망·어시스트 | `playerKill`, `playerDeaths`, `playerAssistant` |
| 딜량·받은 피해 | `damageToPlayer`, `damageFromPlayer` |
| 동물 처치 | `monsterKill` |
| 동물 딜량 | `damageToMonster` |
| 탈출 결과 | `escapeState`: 1 기타 사유 실패, 2 적에 의해 실패, 3 성공 |
| 크레딧 | `totalGainVFCredit` |
| 시야 점수 | `viewContribution` (카메라 개수와 다름) |
| 승률·TOP 2·TOP 3 | 제공된 `gameRank` 표본 중 해당 순위 비율 |
| 경기 RP·증감 | `mmrAfter`, `mmrGain` |

12개 상세 지표, 실험체별 표와 리뷰는 같은 모드·실험체 필터를 사용한다. 평균은 해당 값을 제공한 경기만 분모로 사용하며 0과 미제공을 구분한다. 여러 모드·시즌의 조회 경기 통계는 시즌 누적 통계가 아니다.

상단 현재 시즌 랭크와 점수 그래프는 별도 범위다. 시즌은 `GET /v2/data/Season`, 순위는 `/v1/rank/uid/{uid}/{seasonId}/3`, 누적 성적은 `/v2/user/stats/uid/{uid}/{seasonId}/3`에서 읽는다. `rankPercent`는 0–1 비율을 %로 변환한다. 누적 평균 TK는 `totalTeamKills/totalGames`이다. 시즌·순위 조회 실패가 기존 경기 조회를 막지 않게 처리했다. 모든 공식 API 요청은 기존 1.1초 간격 큐를 통과한다.

공식 문서는 Season 테이블의 열을 별도로 명세하지 않는다. [2026-09-03자 공개 게임 테이블](https://er-data.dakgg.net/db/20260903032313/Season.json)에서 확인한 `seasonID`, `isCurrent:1` 형식을 호환 처리한다. 유일한 현재 시즌 플래그가 없으면 현재 시즌을 추정하지 않는다. 공개 시즌 번호와 API ID가 달라 [시즌 이름 목록](https://er.dakgg.io/api/v1/data/seasons?hl=ko)을 조인한다(2026-09-14 확인: 41 → 시즌 12). 새로운 미등록 ID는 ID를 표시하며 최신 플레이 시즌을 현재 시즌으로 간주하지 않는다. 이후 실제 사용자 키로 공식 Season 응답을 검증했으며 필드는 아래 시즌 전체 조회 항목에 기록했다.

점수 그래프는 시즌 전체 또는 7/30/90일을 선택하고, 한국 시간(UTC+9)의 경기 시작일별로 묶는다. 현재 시즌은 조회일, 과거 시즌은 시즌 종료일을 기준으로 기간을 계산한다. 일별 RP는 해당 날짜에 조회된 마지막 경기의 `mmrAfter`, 일별 증감은 제공된 `mmrGain`의 합계다. 날짜별 툴팁과 표에서 경기 수와 증감 제공 표본 수를 표시한다. `mmrAfter`는 일부 API 이용자에게만 제공되므로 날짜별 마지막 RP가 없으면 일별 증감 그래프를 사용한다. 그날 마지막 경기의 점수가 누락되면 이전 경기 점수를 대신 쓰지 않는다. 기록·점수가 없는 날짜는 null로 비워 두고 다른 시즌은 섞지 않는다. 시간대가 없는 경기 시각은 추정하지 않는다.

### 시즌 전체 조회 (2026-09-14 검증)

RP 선 그래프는 사용자 요청에 따라 기록이 없는 날짜를 건너뛰어 모든 유효 점을 연결한다. 원본 날짜별 점수는 null로 유지하므로 미제공 날짜에 점수나 툴팁 값을 만들어 넣지 않는다.

공식 문서에는 페이지네이션이 생략돼 있지만 실제 경기 목록 응답은 `next`를 제공하고, `/v1/user/games/uid/{uid}?next={next}`가 중복 없이 다음 10경기를 반환하는 것을 확인했다. 응답 커서를 그대로 사용하고, 역행하지 않는 커서가 반복되면 오류를 표시한다. 각 페이지는 중복 경기 ID를 제거하고 선택한 시즌만 합산한다. API 제공 범위 끝 또는 선택 시즌보다 이전 시즌에 도달하면 멈춘다. 100경기 제한을 제거했으며 진행 상태와 확보한 경기 수, 중지·재개를 제공한다.

`/v2/data/Season` 실제 필드는 `seasonID`, `seasonName`, `seasonStart`, `seasonEnd`, `isCurrent`다. 시작·종료의 날짜 부분을 달력 범위로 사용하며 시간대 없는 시각을 UTC로 변환하지 않는다. 시즌 식별은 `seasonId`로 하고, 사용자용 시즌 이름은 검증한 카탈로그를 사용한다. 과거 시즌 RP에 현재 시즌 티어 기준을 소급 적용하지 않는다.

공식 API는 상세 기록을 최근 90일 및 현재 닉네임 사용 기간으로 제한한다. 따라서 `exhausted`는 제공 범위의 조회 완료이며 시즌 전체 확보를 보증하지 않는다. 상단 누적 성적은 시즌 통계 API, 나머지 그래프·실험체 표·상세 지표는 확보한 개별 경기에서 계산한다. 영구 아카이브는 없으며 조회 세션은 마지막 조회부터 30분간 유지한다. 로컬은 메모리·최대 20개 세션, 2026-09-16에 추가한 공개용은 Durable Object SQLite·최대 200개 세션을 사용한다. 공개용은 서버 재시작 후에도 기간 내 조회를 복원한다. 리뷰는 동일 조회 세션의 선택 범위 중 최근 최대 100경기로 제한하고 그 범위를 명시한다. [공개용 저장·요청 제한](../cloudflare-deployment.md)을 참고한다.

경기 카드 색상은 사용자 지정에 따라 1등의 기존 라임색을 유지하고, 그 외에는 탈출 성공(초록), 탈출 실패(빨강), 2~3등(파랑) 순서로 적용한다. 탈출 상태가 누락되거나 0/알 수 없는 코드이면 실패로 간주하지 않는다. 등수와 성공·실패 문구를 함께 표시한다.

순위 흐름 섹션은 제거했다. 실험체별 표는 실험체 이름 다음에 승률, RP 증감, 경기 수, 평균 TK/K, 평균 딜량, 평균 시야 점수, 평균 동물 딜량 순서로 표시한다. 동물 처치 수와 동물에게 가한 피해량을 구분한다.

## 티어

[공식 랭크 안내(2026-08-19 갱신)](https://support.playeternalreturn.com/hc/en-us/articles/21812479709081-Rank-System-Tiers) 기준이다. 패치의 변경 가능성이 있어 추후 갱신이 필요하다.

| 티어 | IV / III / II / I 최소 RP |
|---|---|
| 아이언 | 0 / 150 / 300 / 450 |
| 브론즈 | 600 / 800 / 1000 / 1200 |
| 실버 | 1400 / 1650 / 1900 / 2150 |
| 골드 | 2400 / 2700 / 3000 / 3300 |
| 플래티넘 | 3600 / 3950 / 4300 / 4650 |
| 다이아몬드 | 5000 / 5350 / 5700 / 6050 |
| 메테오라이트 | 6400 / 6700 / 7000 / 7300 |

미스릴은 7600부터다. 데미갓·이터니티는 단일 `serverRank`와 RP만으로 확정할 수 없다. [시즌 11 보상 정책](https://playeternalreturn.com/posts/news/3704?hl=ko-KR)은 복수 서버 참여·순위 조건을 명시한다. 시즌 12의 정확한 승급 판정을 확보하기 전에는 7600 이상을 **미스릴 이상**으로 표시하고 실제 순위·RP는 그대로 보여준다. 시즌 경기 수가 명시적으로 0이면 티어를 붙이지 않는다.

## 게임 이미지

게임 이미지의 원 권리자는 Nimble Neuron이다. 공개 DAK.GG 카탈로그의 ID·한국어 이름·등급·이미지 URL을 최소 스냅샷으로 저장했다. DAK.GG의 전적 API를 사용자 전적 조회에 사용하지 않으며, 해당 서비스에 사용자 닉네임이나 ER 키를 전달하지 않는다. 이미지는 공개 CDN URL로 표시한다.

- [캐릭터 90개](https://er.dakgg.io/api/v1/data/characters?hl=ko)
- [아이템 1,013개](https://er.dakgg.io/api/v1/data/items?hl=ko)
- [특성 140개](https://er.dakgg.io/api/v1/data/trait-skills?hl=ko)
- [전술 스킬 44개](https://er.dakgg.io/api/v1/data/tactical-skills?hl=ko)
- [티어 이미지 11개](https://er.dakgg.io/api/v1/data/tiers?hl=ko)

`lib/generated/game-assets.json`은 `npm run sync:assets`로 수동 갱신한다. 특성·전술 스킬의 이미지 파일명은 코드와 다를 수 있으므로 반환된 URL을 그대로 사용한다. 알 수 없는 ID나 CDN 오류는 코드·대체 텍스트로 표시한다. 과거 패치의 아이템 이미지·이름을 경기 시점별로 복원하지는 않는다. 공개 접근 가능 여부가 별도 재배포 라이선스를 의미하지 않으며 공개 서비스화 전 리소스 이용 조건을 확인해야 한다.

## 검증 범위

자동 테스트로 필드 연결, 0/미제공 구분, 시즌 분리, RP 누락, 티어 경계값, 공식 API 경로 조인 및 부분 실패 복구를 확인했다. 기존 Codex HTTP 테스트는 확장된 경기 객체를 실제 클라이언트 함수로 전송하여 이미지 메타데이터가 고정 리뷰 계약에서 제외됨을 검증한다. 최초 이미지·지표 확장 때는 실제 ER·Codex 호출을 반복하지 않았으나, 이후 2026-09-14에 실제 ER 키로 닉네임·시즌·랭크·경기를 조회하고 물방개 시즌 12의 랭크 170경기를 확보했다. 2026-09-15에는 34개 자동 테스트와 타입 검사를 통과했으며, 실제 ER·Codex 호출은 반복하지 않았다.
